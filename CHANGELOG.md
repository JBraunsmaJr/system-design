# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

Add each change as a line item under `[Unreleased]`. Start an item with
`[MAJOR]`, `[MINOR]` or `[PATCH]` when it should move the version; the
release takes the highest marker present (resetting the lower parts) and
fails if there is none. Items without a marker are still published. The
markers are removed when the section becomes a release. See
[docs/releasing.md](docs/releasing.md).
